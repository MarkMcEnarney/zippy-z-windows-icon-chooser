# Contributing

Thank you for considering a contribution to Zippy Z.

- Open an Issue to describe reproducible bugs, Windows 11 version, file association and security-product detection details.
- Submit a Pull Request with a concise explanation and, for Windows GUI changes, screenshots where relevant.
- Please do not upload copyrighted third-party logos, archive-software icons, or materials you cannot license under MIT.
- Do not introduce telemetry, downloads, elevation prompts, execution-policy bypasses, or broad security exclusions without documented necessity and review.
- Changes to icon persistence and Registry restore should include evidence of testing and should not affect the application used to open ZIP files.

Please keep your contributions compatible with the MIT licence and preserve attribution to Mark McEnarney for the original project.
