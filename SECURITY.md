# Security

Zippy Z changes Windows per-user Registry icon settings and therefore should be treated as executable system-customisation software.

**Avoid bypassing antivirus or SmartScreen protections to run it.** Until successful real-Windows testing is documented, releases are marked as pre-release.

For security concerns, open a GitHub Issue without including secrets or personal information. Do not restore an antivirus quarantine entry merely to test Zippy Z.
