# Zippy Z 2.0.1 — Pre-release

Native 64-bit Windows ZIP icon chooser with nine icon designs, an About dialog crediting Mark McEnarney, and a restore option. No PowerShell or CMD launcher; no background service or internet requests.

**Testing status:** compiled and statically checked; has **not** been run in the target Windows 11 environment. Please treat as a pre-release and report defects or antivirus detections without disabling protection.

**Installation:** download `Zippy-Z-Windows11-x64-v2.0.1.zip`, Extract All, then run `ZippyZ.exe`. The `Icons` folder must remain alongside the executable. The chosen icon is copied to `%LOCALAPPDATA%` after Apply.
